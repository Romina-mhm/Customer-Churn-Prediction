# Customer Churn Prediction on the IBM Telco Dataset

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/14cM8U-D3MXI3c6gYQI1KaqtMmcBOTarH?usp=sharing)

Final project for the **Machine Learning** course at the University of Bologna,
Cesena Campus (A.Y. 2024-2025), Prof. Matteo Francia.

The project builds a customer churn prediction pipeline on the public IBM Telco
dataset, following the CRISP-DM methodology. Five classifiers are compared
(Dummy, Logistic Regression, Decision Tree, Random Forest, MLP) and the best
models reach an F1 of about 0.62 and a ROC-AUC of about 0.84 on the test set.

## Files

- `Customer_Churn_Prediction_Notebook.ipynb` — full pipeline (data understanding,
  preparation, modeling, evaluation). Click the badge above to open it directly
  in Google Colab.
- `Customer Churn Prediction_paper.pdf` — paper following the IEEE
  template.
- `Customer_Churn_Presentation.pdf` — presentation slides.

## How to run

Click the **Open in Colab** badge above. The dataset is loaded directly from a
public URL inside the notebook, so no file upload is needed. Then run all
cells from top to bottom (Runtime → Run all).

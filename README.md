# Customer Churn Prediction on the IBM Telco Dataset

Final project for the **Machine Learning** course at the University of Bologna,
Cesena Campus (A.Y. 2024-2025), Prof. Matteo Francia.

## Files

- `Customer_Churn_Prediction_Notebook.ipynb` — full pipeline in Google Colab
  (data understanding, preparation, modeling, evaluation)
- `Customer Churn Prediction_paper.pdf` — paper following the IEEE template
- `Customer_Churn_Presentation.pdf` — presentation slides

## How to run

Open the notebook in Google Colab and run all cells. The dataset is loaded
directly from a public URL, no upload is needed.
